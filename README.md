# Échos Solidaires

Site statique d'Échos Solidaires, exporté depuis Webflow (echos-solidaires.webflow.io) pour être hébergé indépendamment.

- `index.html` : page d'accueil
- `infos-pratiques.html` : infos pratiques
- `404.html` : page introuvable
- `css/`, `js/`, `fonts/`, `images/` : ressources locales (aucune dépendance au CDN Webflow)

## Voir le site en local

```
python3 -m http.server
```

puis ouvrir http://localhost:8000

## Mise en ligne

Compatible GitHub Pages : Settings → Pages → « Deploy from a branch » → `main` / `(root)`.
